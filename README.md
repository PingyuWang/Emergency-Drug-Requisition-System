# Emergency-Drug-Requisition-System
藥品緊急請領作業系統
====
版本：

V3.9
修正藥庫工作站漏提醒的問題：具備藥庫作業權限的同仁（例如主管）若改用手機、網頁或桌機的一般入口起單，工作站先前會誤判為藥庫自行開立而不提醒；現改依實際建單來源判斷，只有「網頁藥庫工作台」與「桌機代客建單」不提醒，其餘一律提醒
修正網路不穩時可能漏掉單據異動的問題：先前若查詢有無異動成功、但接著取得完整清單失敗，該次的完成／欠藥／刪除等異動會被永久略過，畫面停在舊資料且不會有任何提示；現改為完整取得資料後才記錄進度，未取得則下一輪自動重試

v3.8
修正建單時遇到超長藥名（疫苗、營養輸液類）版面被撐開，右側「調撥庫別／請領量／交給誰／調撥原因／領藥號碼／備註」欄位被推出視窗邊界的問題
藥師建單頁與藥庫工作站代客建單頁皆已修正，長藥名改為自動換行顯示
新增測試環境獨立入口：連線非正式環境時標題列標示並於啟動時提醒，且不執行自動更新（正式環境操作完全不變）
藥庫工作站代客建單頁新增「開單者」常駐顯示與「換人」按鈕，避免前一位同仁離開後由下一位接手續開，單據仍記在前一位名下
登出時清空建單頁：日期區間回復為今天、表單欄位與歷史清單一併清除，避免下一位登入者沿用前一位的查詢區間或誤送出前一位未完成的內容

修正匯出跨區間資料時，超過200筆較舊資料被漏匯、結束日當天被漏匯的問題
